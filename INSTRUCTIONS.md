# FRIDAY — Повна інструкція та посібник користувача (Windows)

**FRIDAY** — це швидкий локальний фоновий голосовий асистент для Windows, орієнтований на розробників. Він працює у фоні майже з нульовим споживанням ресурсів (`CPU ≈ 0%`), прокидається лише за гарячою клавішею (**Hold-to-Talk**), розуміє українську мову з англійськими технічними термінами (`FastAPI`, `traceback`, `pydantic`, `git`) і виконує більшість дій миттєво без звернення до LLM.

## 1. Що вміє FRIDAY (Повний перелік можливостей)

Усі можливості FRIDAY побудовані як окремі навички (**Skills**):

### 1.1 Керування вікнами та моніторами (`window.*`)
- **Переміщення між моніторами (`window.move`)**: переносить активне або вказане вікно (браузер, редактор, термінал, Telegram) на потрібний монітор з автоматичним розгортанням або позиціонуванням.
- **Прикріплення (Snap) (`window.move`)**: притискає вікно до лівої чи правої половини робочої області монітора або центрує його (з урахуванням прихованих рамок Windows 10/11 та DPI).
- **Зміна розміру (`window.resize`)**: збільшує або зменшує вікно на 10–15% від робочої області монітора, розгортає на весь екран (`maximize`) або повертає попередній розмір (`restore`).
- **Перемикання фокусу (`window.focus`)**: виводить потрібну програму на передній план (навіть якщо поточне вікно утримує фокус).

### 1.2 Запуск програм за білим списком (`app.launch`)
- Відкриває дозволені програми, прописані у `[apps]` файлу `config.toml` (наприклад, VS Code, Chrome, Telegram Desktop).
- Жодна випадкова команда не може запустити довільний `.exe` чи shell-скрипт поза білим списком.

### 1.3 Голосовий ввід тексту (`text.type`)
- Вводить продиктований текст у будь-яке активне текстове поле (редактор коду, месенджер, браузер, нотатки).
- Працює через тимчасову підміну буфера обміну + `Ctrl+V`, після чого **автоматично відновлює** попередній вміст вашого буфера обміну. Це гарантує миттєву вставку кирилиці та спецсимволів без помилок розкладки клавіатури.

### 1.4 Вебпошук та швидке відкриття сайтів (`web.search`)
- Шукає запит у Google у браузері за замовчуванням.
- Вміє шукати прицільно на конкретному сайті через оператор `site:` (наприклад, документація Python, FastAPI, Pydantic, MDN).

### 1.5 «Помилка → Документація» (`docs.lookup`)
- **Кілер-фіча для розробника**: ви копіюєте стек-трейс або помилку з термінала/IDE (`Ctrl+C`) і натискаєте `Ctrl+Alt+D` (або кажете голосом *«покажи документацію по цій помилці»*).
- FRIDAY:
  1. Читає буфер обміну (бере перший рядок помилки та останні ~40 рядків `traceback`).
  2. Евристично (або через швидкий запит до LLM) визначає бібліотеку (`python`, `fastapi`, `pydantic` тощо) і тип винятку (`TypeError`, `ValidationError`, `ModuleNotFoundError`).
  3. Відкриває **нове вікно браузера** з релевантною документацією.
  4. Автоматично переносить це вікно на **другий монітор** (`monitors.docs`).
  5. **Повертає фокус назад у ваш редактор коду**, щоб ви не переривали роботу.

### 1.6 Надсилання повідомлень у Telegram (`telegram.send`)
- Надсилає повідомлення контакту напряму через Telegram API (`telethon`), без емуляції миші чи відкриття вікна Telegram.
- Знаходить контакт за нечітким пошуком імені серед ваших діалогів.
- **Завжди питає підтвердження** перед відправленням через спливаюче сповіщення (toast).

### 1.7 Інтеграція з Antigravity CLI (`agent.run`)
- Складні інженерні задачі (*«відрефактори цей файл»*, *«напиши тести для модуля»*, *«поясни архітектуру»*) передає в **Antigravity CLI** у контексті поточної робочої директорії проєкту.
- Режим `auto_approve` примусово вимкнений (`false`) — будь-які зміни файлів потребують вашого ручного підтвердження.

### 1.8 Керування вікнами жестами руки (`gesture.drag` — Етап A)
- Дозволяє переносити вікна між трьома моніторами жестом **«щипок»** (зведення великого та вказівного пальців перед веб-камерою):
  - **Режим `drag`**: утримуйте щипок `≥ 150 мс` — активне вікно плавно рухається за вашою рукою по віртуальному робочому столу всіх моніторів (згладжування фільтром One Euro, частота оновлення позиції обмежена до `~30 Гц`). Відпустіть щипок над потрібним монітором — вікно автоматично розгорнеться на ньому.
  - **Режим `swipe`**: зробіть щипок і різко проведіть рукою вліво або вправо (`< 1 с`) — вікно перескочить на сусідній монітор у відповідному напрямку.
- **Приватність і продуктивність**: камера (`640x480 @ 20 FPS`) вмикається лише під час утримання гарячої клавіші `Ctrl+Alt+G` (або запуску навички `gesture.drag`) і автоматично звільняється після `idle_timeout_s` секунд бездіяльності. Відео нікуди не зберігається і не передається.
- **Безпека та скасування**: натискання `Esc` під час перетягування миттєво скасовує дію і повертає вікно на початкове місце. Робочий стіл, панель завдань та вікна з правами Адміністратора захищені від переміщення.

Утримуйте `Right Ctrl`, скажіть фразу і відпустіть клавішу:

| **Зміна розміру** | *«Збільш це вікно»* / *«Зменш вікно»* / *«Розгорни на весь екран»* | `window.resize` (`target="active"`, `mode="bigger" \| "smaller" \| "maximize"`) |

## 4. Повний туторіал: встановлення та перший запуск

### Крок 1. Вимоги до системи
- **ОС**: Windows 10 або Windows 11 (x64).
- **Python**: версія **3.11** або новіша (перевірено на Python 3.12).
- **Мікрофон**: будь-який робочий вхідний аудіопристрій у системі.

### Крок 2. Клонування репозиторію та створення віртуального середовища
Відкрийте PowerShell у папці проєкту `C:\Users\Acer\Friday`:

```powershell
# 1. Створити ізольоване віртуальне середовище
python -m venv .venv

# 2. Встановити проєкт та залежності для розробки/тестів
.\.venv\Scripts\pip.exe install -e ".[dev]"
```

*(Опційно)* Якщо ви плануєте використовувати **офлайн-розпізнавання мовлення** (`faster-whisper`) або інтеграцію з **Telegram** (`telethon`), встановіть додаткові залежності:

```powershell
.\.venv\Scripts\pip.exe install -e ".[whisper,telegram,dev]"
```

### Крок 3. Налаштування секретів (`.env`)
Скопіюйте шаблон `.env.example` у файл `.env`:

```powershell
Copy-Item .env.example .env
```

Відкрийте `.env` у редакторі та заповніть ключі:

```ini
# Обов'язково для STT (режим gemini) та розумного роутера (LLM parser)
GEMINI_API_KEY=ваш_ключ_від_Google_AI_Studio

# Потрібно лише для навички відправки повідомлень у Telegram (Етап 7)
# Отримати можна на https://my.telegram.org -> API development tools
TELEGRAM_API_ID=12345678
TELEGRAM_API_HASH=ваш_telegram_api_hash
```

> **Важливо:** файл `.env` та файли сесій `*.session` додані у `.gitignore` і ніколи не потрапляють у Git.

### Крок 4. Перевірка працездатності та запуск
Спочатку запустіть автоматичні тести та перевірочний старт:

```powershell
# Запуск тестів
.\.venv\Scripts\pytest.exe -v

# Швидка перевірка конфігурації та ініціалізації (завершиться одразу)
.\.venv\Scripts\python.exe -m friday --once
```

Для повноцінного запуску асистента у фоні виконайте:

```powershell
.\.venv\Scripts\python.exe -m friday
```

Зупинити програму в терміналі можна комбінацією `Ctrl+C`.

## 5. Налаштування конфігурації (`config.toml` та `.env`)

Усі несекретні налаштування знаходяться у файлі [`config.toml`](./config.toml):

```toml
[hotkeys]
voice = "right_ctrl"               # Клавіша Hold-to-Talk (утримувати під час мовлення)
explain_clipboard = "ctrl+alt+d"   # Миттєвий пошук документації за traceback у буфері
cancel = "esc"                     # Скасування поточної дії або відмова у Confirm Gate

[audio]
sample_rate = 16000                # Частота дискретизації (16 кГц оптимально для STT)
max_seconds = 15                   # Захист від залипання клавіші (макс. тривалість запису)
tail_ms = 200                      # Дозапис 200 мс після відпускання клавіші, щоб не обрізати кінцівки слів

[stt]
backend = "gemini"                 # "gemini" (хмарний, ~0 МБ RAM) або "whisper_local" (офлайн, модель small int8)
language = "uk"                    # Основна мова розпізнавання
model = "gemini-3.5-transcribe"    # Модель транскрибації Gemini

[llm]
model = "gemini-3.5-flash-lite"    # Швидка модель для Smart Path (вивід суворо у форматі JSON)

[monitors]
primary = 0                        # Індекс основного монітора (починаючи з 0)
docs = 1                           # Індекс монітора, куди відкриватиметься документація

[apps]                             # Білий список програм: логічна назва -> команда або шлях
code = "code"
telegram = "C:\\Users\\Acer\\AppData\\Roaming\\Telegram Desktop\\Telegram.exe"
browser = "chrome"

[docs_sites]                       # Домени для прицільного пошуку документації за бібліотекою
python = "docs.python.org"
fastapi = "fastapi.tiangolo.com"
pydantic = "docs.pydantic.dev"
mdn = "developer.mozilla.org"

[agent]
command = "antigravity"            # Команда виклику CLI-агента
auto_approve = false               # ЗАВЖДИ false! Спроба поставити true викличе помилку валідації
```

## 6. Гарячі клавіші та керування

| Клавіша (за замовчуванням) | Режим | Призначення |
|---|---|---|
| **Утримувати `Right Ctrl`** | Hold-to-Talk | Починає запис голосу при натисканні; після відпускання (+ `200 мс`) відправляє аудіо на розпізнавання та виконання. Записи коротші за `300 мс` ігноруються (захист від випадкових натискань). |
| **`Ctrl + Alt + D`** | Натискання | Читає помилку/traceback із буфера обміну і відкриває документацію на моніторі `docs` без втрати фокусу редактора. |
| **`Esc`** | Натискання | Скасовує поточну тривалу дію або відхиляє запит на підтвердження (`Confirm Gate`). |
| **`Enter`** *(під час Confirm Gate)* | Натискання | Підтверджує виконання чутливої дії (наприклад, відправку повідомлення у Telegram). |

## 7. Автозапуск у фоновому режимі (без вікна консолі)

Щоб FRIDAY запускався разом із Windows і не тримав відкритим вікно термінала, використовуйте `pythonw.exe` з віртуального середовища:

### Варіант А — Через папку автозавантаження (`shell:startup`)
1. Натисніть `Win + R`, введіть `shell:startup` і натисніть `Enter`.
2. Створіть ярлик (Shortcut) зі шляхом:
   ```text
   C:\Users\Acer\Friday\.venv\Scripts\pythonw.exe -m friday
   ```
3. У полі **Робоча папка (Start in)** обов'язково вкажіть:
   ```text
   C:\Users\Acer\Friday
   ```

### Варіант Б — Через Планувальник завдань (Task Scheduler) з PowerShell
```powershell
$Action = New-ScheduledTaskAction `
    -Execute "C:\Users\Acer\Friday\.venv\Scripts\pythonw.exe" `
    -Argument "-m friday" `
    -WorkingDirectory "C:\Users\Acer\Friday"
$Trigger = New-ScheduledTaskTrigger -AtLogOn
Register-ScheduledTask -TaskName "FridayVoiceAssistant" -Action $Action -Trigger $Trigger -Description "FRIDAY Background Voice Assistant"
```

## 8. Безпека та підтвердження дій (Confirm Gate)

FRIDAY спроєктований із принципом **Safety First**:

1. **Білий список запуску (`[apps]`)**: голосові команди не можуть викликати довільні системні бінарники — лише ключі зі словника `[apps]` у `config.toml`.
2. **Блокування деструктивних команд (`safety.py`)**: патерни на кшталт `rm -rf`, `rmdir /s`, `del /f`, `format`, `reg add/delete`, `git reset --hard`, `git push --force`, `shutdown` автоматично перехоплюються і блокуються.
3. **Захист секретів**: доступ до `.env`, `id_rsa`, `*.pem`, `*.key`, `*.session` заблоковано на рівні коду; у логах секрети маскуються (`***`).
4. **Поріг впевненості (`confidence < 0.7`)**: якщо команда розпізнана нечітко або шумно, FRIDAY не вгадує дію, а перепитує через `clarify`.
5. **Обов'язковий Confirm Gate**: відправка повідомлень у Telegram та запуск змін через CLI-агента завжди вимагають явного підтвердження користувача.

## 9. Діагностика, логування та вирішення проблем

### Де дивитися логи та таймінги?
Усі події та час виконання кожного етапу записуються у файл:
- **`C:\Users\Acer\Friday\logs\friday.log`** (автоматична ротація при досягненні 2 МБ, зберігається до 3 архівних копій).

Приклад рядка в логу:
```text
2026-10-22 16:49:55 | INFO    | friday.timing | ⏱ Етап [startup.load_config] виконано за 2.56 мс
```

### Типові проблеми та їх вирішення

1. **Вікно іншої програми не переміщується або не отримує фокус**
   - **Причина**: цільова програма (наприклад, термінал або IDE) запущена **від імені Адміністратора**, а FRIDAY — від звичайного користувача. Механізм Windows UIPI блокує керування процесами з вищими привілеями.
   - **Рішення**: запускайте обидві програми з однаковим рівнем прав.

2. **Гаряча клавіша не спрацьовує або запис обривається**
   - Перевірте, чи утримуєте ви клавішу довше за `300 мс` (коротші натискання відкидаються як випадкові).
   - Під час діагностики записані аудіофайли зберігаються у папці `temp/` для перевірки якості звуку з мікрофона.

3. **Помилка `GEMINI_API_KEY не задано`**
   - Переконайтеся, що у корені проєкту існує файл `.env` (не тільки `.env.example`) і в ньому вказано валідний ключ `GEMINI_API_KEY=...`, або перемкніть `backend = "whisper_local"` у `config.toml`.
