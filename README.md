# 🎙️ FRIDAY — Персональний голосовий та жестовий асистент для Windows

[![Python](https://img.shields.io/badge/Python-3.11%20%7C%203.12-blue.svg)](https://www.python.org/)
[![Platform](https://img.shields.io/badge/Platform-Windows%2010%20%2F%2011-0078D6.svg)](https://www.microsoft.com/windows)
[![License](https://img.shields.io/badge/License-MIT-green.svg)](LICENSE)
[![Tests](https://img.shields.io/badge/Tests-85%20passed-brightgreen.svg)]()

**FRIDAY** — це автономний локальний фоновий асистент для Windows, що поєднує **голосове керування** (українською мовою через Google Gemini або Faster-Whisper), **комп'ютерний зір і керування жестами рук** (MediaPipe + вебкамера), а також **кіберпанк-інтерфейс налаштування (Launcher)** на PySide6.

---

## ✨ Основні можливості

### 🎤 1. Голосове керування (Hold-to-Talk)
* **Миттєвий відгук**: Затисніть `Right Ctrl` (або іншу налаштовану клавішу) і говоріть. Розпізнавання та виконання починається одразу після відпускання.
* **Українська мова "з коробки"**: Висока точність розпізнавання завдяки хмарному `gemini-3.5-transcribe` або локальному `faster-whisper`.
* **Гібридний маршрутизатор**: 
  - Швидкі детерміновані правила (Regex) обробляють команди за < 5 мс без інтернет-запитів.
  - Складні розмовні фрази парсяться через легку модель `gemini-3.5-flash-lite`.

### ✋ 2. Керування вікнами жестами рук (Вебкамера + MediaPipe)
* **Режим Toggle (`Ctrl + Tab`)**: Натисніть `Ctrl + Tab`, щоб увімкнути вебкамеру, і натисніть ще раз, щоб вимкнути — тримати клавішу не потрібно!
* **Розумне захоплення вікна**: Асистент автоматично захоплює саме те вікно, над яким знаходиться ваша рука, активує його та виводить на передній план.
* **Одноручний переніс (Drag & Snap)**:
  - Зімкніть великий і вказівний пальці (щипок) — вікно слідує за рукою.
  - Розкрийте долоню — вікно прилипає до поточного монітора та розгортається на весь екран.
* **Дворучний динамічний ресайз**:
  - Утримуючи вікно однією рукою, піднесіть другу й зробіть другий щипок.
  - **Розводьте руки в сторони**, щоб збільшити розмір вікна, або **зводьте разом**, щоб зменшити його в реальному часі.
* **Закриття вікна кулаком (Fist)**:
  - Стисніть руку в кулак під час перетягування — вікно буде плавно і безпечно закрито (`WM_CLOSE`).
* **Жест Swipe**:
  - Різкий помах рукою вліво/вправо миттєво перекидає вікно на сусідній монітор у мультимоніторних конфігураціях.
* **Фільтрація тремтіння**: Алгоритм `OneEuroFilter2D` згладжує рухи рук до ~30 Гц без затримок і стрибків.

### 🪟 3. Системні навички та автоматизація
* **Керування вікнами**: Переміщення між моніторами («перенеси на другий монітор», «розгорни на повний екран», «закрий вікно»).
* **Запуск програм**: Запуск додатків із білого списку за назвами або сленговими синонімами («відкрий вс код», «запусти браузер», «відкрий телеграм»).
* **Робота з файлами**: Створення та відкриття файлів у безпечних дозволених директоріях («створи файл main.py», «відкрий нотатки»).
* **Швидка документація (`Ctrl + Alt + D`)**: Скопіюйте назву функції або тексту помилки — натисніть хоткей, і асистент відкриє офіційну документацію на призначеному моніторі.
* **Диктовка тексту**: Введення озвученого тексту в активне текстове поле.
* **Telegram**: Надсилання повідомлень контактам через офіційний клієнт Telethon.
* **Antigravity CLI**: Виконання завдань розробки через автономні AI-агенти.

### 🖥️ 4. FRIDAY Cyber Launcher
* Графічний інтерфейс на базі **PySide6** з неоновою темою:
  - Тестування рівня мікрофона з живим графіком.
  - Візуальне налаштування та перевірка конфліктів гарячих клавіш.
  - Налаштування порогів чутливості щипка та вибору вебкамери.
  - Управління білими списками застосунків, сайтів документації та папок.

## 🚀 Покроковий туторіал запуску для тестування

### Крок 1. Передумови
- **ОС**: Windows 10 або 11 (64-bit).
- **Python**: версія `3.11` або `3.12` ([завантажити з python.org](https://www.python.org/downloads/)). *Обов'язково позначте галочку "Add Python to PATH" під час встановлення!*
- **Обладнання**: Мікрофон і вебкамера (для жестів).

### Крок 2. Клонування репозиторію
Відкрийте термінал (PowerShell або командний рядок) у зручній папці:
```powershell
git clone https://github.com/vavun/Friday.git
cd Friday
```

### Крок 3. Створення та активація віртуального середовища
```powershell
python -m venv .venv
.\.venv\Scripts\activate
```

### Крок 4. Встановлення залежностей
```powershell
pip install --upgrade pip
pip install -r requirements.txt
pip install -e .
```

### Крок 5. Налаштування API-ключа
1. Скопіюйте файл-зразок `.env.example` у файл `.env`:
   ```powershell
   copy .env.example .env
   ```
2. Відкрийте файл `.env` у будь-якому текстовому редакторі (наприклад, `Notepad .env`) та вкажіть ваш безкоштовний ключ Gemini API:
   ```env
   GEMINI_API_KEY=AIzaSy...
   ```
   > 💡 Отримати безкоштовний ключ можна за 1 хвилину на [Google AI Studio](https://aistudio.google.com/).

### Крок 6. Запуск

#### Варіант A: Графічний Launcher (рекомендовано для налаштування)
```powershell
python -m friday.launcher
```
У Лаунчері ви зможете перевірити мікрофон, налаштувати хоткеї та переглянути активні модулі.

#### Варіант B: Запуск фонового асистента напряму
```powershell
python -m friday
```

## ⌨️ Гарячі клавіші за замовчуванням

| Клавіша | Дія | Опис |
| :--- | :--- | :--- |
| **`Right Ctrl`** | Голосова команда | Затиснути $\rightarrow$ сказати фразу $\rightarrow$ відпустити |
| **`Ctrl + Tab`** | Режим жестів | Натиснути 1 раз для вмикання камери; натиснути ще раз для вимикання |
| **`Ctrl + Alt + D`**| Документація | Відкриває документацію для помилки чи символу з буфера |
| **`Esc`** | Скасування | Скасовує поточне перетягування вікна, запис або дію |
| **`Enter`** | Підтвердження | Підтверджує виконання потенційно чутливої дії (якщо увімкнено safety) |

## ✋ Шпаргалка жестів для камери

1. **Щипок однією рукою** (великий + вказівний пальці разом):
   - Захоплює вікно під рукою і починає плавне перетягування.
2. **Розкриття долоні**:
   - Відпускає вікно і максимізує його на моніторі, де знаходиться рука.
3. **Дві руки у щипку**:
   - Тримаючи вікно однією рукою, складіть щипок другою:
   - Розведення рук збільшує вікно, зведення — зменшує.
4. **Кулак (Fist)**:
   - Якщо під час утримання стиснути пальці в кулак — вікно закривається.
5. **Swipe (різкий помах)**:
   - Якщо в конфігурації увімкнено `mode = "swipe"`, різкий горизонтальний рух щипком перекидає вікно на сусідній екран.

## 🔒 Безпека та приватність

- **Ізоляція секретів**: Ваші особисті ключі (`.env`), персональні налаштування (`config.local.toml`) та історія логів автоматично ігноруються Git і ніколи не потраплять у відкритий репозиторій.
- **Захист системних вікон**: Системні компоненти Windows (панель завдань `Shell_TrayWnd`, робочий стіл `Progman`/`WorkerW`) захищені від випадкового закриття чи переміщення.
- **Білі списки шляхів**: Асистент має доступ лише до тих папок, які явно дозволені в конфігурації (`[paths]`).
